## [cite_start]2. DB 테이블 설계 (`deliveries`) [cite: 153, 154]

Supabase PostgreSQL 데이터베이스에 적용할 테이블 구조입니다. [cite_start]컬럼명은 영어 소문자, 테이블명은 복수형 규칙을 엄격히 준수합니다[cite: 154, 177].

| 컬럼명 (Column) | 데이터 타입 (Type) | 제약조건 (Constraint) | 설명 |
| :--- | :--- | :--- | :--- |
| [cite_start]**`id`** [cite: 155] | [cite_start]`UUID` [cite: 161] | Primary Key, Default: `gen_random_uuid()` | [cite_start]고유 식별자 (자동 생성) [cite: 155, 161, 178] |
| [cite_start]**`name`** [cite: 161] | [cite_start]`TEXT` [cite: 161] | Not Null | [cite_start]배달 식당/가게 이름 [cite: 161, 178] |
| [cite_start]**`category`** [cite: 161] | [cite_start]`TEXT` [cite: 161] | - | [cite_start]음식 카테고리 (치킨, 피자, 한식, 야식 등) [cite: 161, 178] |
| [cite_start]**`app_name`** [cite: 161] | [cite_start]`TEXT` [cite: 161] | - | [cite_start]주요 이용 배달앱 (배민, 쿠팡이츠, 요기요 등) [cite: 113, 161] |
| [cite_start]**`min_order`** [cite: 161] | [cite_start]`INTEGER` [cite: 161] | Default: `0` | [cite_start]최소주문금액 (원 단위, 예: 15000) [cite: 161] |
| [cite_start]**`rating`** [cite: 161] | [cite_start]`INTEGER` [cite: 161] | Default: `5` | [cite_start]만족도 평점 (1~5점) [cite: 161, 178] |
| [cite_start]**`memo`** [cite: 161] | [cite_start]`TEXT` [cite: 161] | - | [cite_start]추천 메뉴 및 솔직한 한줄평 [cite: 161, 178] |

### [cite_start]💻 Supabase SQL Script [cite: 130]
```sql
create table deliveries (
  id uuid default gen_random_uuid() primary key,
  name text not null,
  category text,
  app_name text,
  min_order integer default 0,
  rating integer default 5,
  memo text,
  user_id uuid references auth.users,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);

-- Row Level Security (RLS) 설정
alter table deliveries enable row level security;

create policy "본인 데이터 조회" on deliveries for select using (auth.uid() = user_id);
create policy "본인 데이터 생성" on deliveries for insert with check (auth.uid() = user_id);
create policy "본인 데이터 수정" on deliveries for update using (auth.uid() = user_id);
create policy "본인 데이터 삭제" on deliveries for delete using (auth.uid() = user_id);
