■ 서비스명
배달노트 (Delivery Note)

■ 한 줄 정의
최소주문금액, 이용 배달앱, 맛 만족도를 기록해두고 실패 없이 배달 음식을 시켜 먹는 개인용 배달 맛집 앱

■ DB 테이블 설계 (deliveries)
- id (UUID, PK, 자동 생성)
- name (TEXT, 식당명)
- category (TEXT, 음식 카테고리: 치킨/피자/한식 등)
- app_name (TEXT, 주요 이용 배달앱: 배민/쿠팡이츠/요기요 등)
- min_order (INTEGER, 최소주문금액: 숫자, 예: 15000)
- rating (INTEGER, 평점: 1~5점)
- memo (TEXT, 추천 메뉴 및 솔직한 한줄평)
- user_id (UUID, 사용자 ID - Supabase Auth 연동)
- created_at (TIMESTAMP, 등록일시, 자동 생성)

■ 화면 3개
1. 목록 화면: 음식 카테고리/배달앱 필터 + 최소주문금액순 정렬 + 배달 맛집 카드 목록
2. 상세 화면: 식당 정보, 최소주문금액, 이용 앱, 한줄평, 수정/삭제 버튼
3. 등록 화면: 식당명, 카테고리, 최소주문금액, 이용 앱, 평점, 메모 입력폼

■ 안 만들 것 (Scope 제외)
구독 멤버십 자동 계산 로직, 배달 앱 외부 링크 연동, 지도/위치 추적, 사진 업로드, 결제 및 장바구니 기능
